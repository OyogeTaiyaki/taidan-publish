taidan publish

A private desktop tool used only by the owner of the YouTube channel スタジオともしび (Studio Tomoshibi) to set the title, description, thumbnail, captions, synthetic content disclosure and scheduled publish time of the owner's own videos through YouTube API Services. It is not offered to the public.

YouTube チャンネル「スタジオともしび」の持ち主だけが使う手元の道具です。YouTube API サービスを通して、持ち主自身の動画の題・説明・サムネイル・字幕・合成コンテンツの開示・予約公開の時刻を設定します。一般には公開していません。
