Privacy Policy — taidan publish

Last updated: 2026-10-01

taidan publish ("the Tool") is a private desktop tool used only by the owner of the YouTube channel スタジオともしび (Studio Tomoshibi, "we") to set the title, description, thumbnail, captions, altered/synthetic content disclosure and scheduled publish time of videos that the owner has uploaded to that channel. The Tool is not offered to the public and has no other users.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

What the Tool accesses

With the owner's authorization (OAuth scope https://www.googleapis.com/auth/youtube.force-ssl), the Tool reads and updates the metadata (title, description, tags, privacy status, scheduled publish time, synthetic media disclosure), thumbnail and caption tracks of the owner's own videos, and reads the channel name to confirm which channel was authorized. It does not access any other user's data, comments, analytics or personal information.

What the Tool stores

The OAuth token is stored only on the owner's own computer (outside of any shared or public location). The Tool keeps a local record of what it sent (video ID, title, settings) for the owner's reference. No data is sent to any server other than Google's YouTube API, and nothing is sold or shared with third parties. The Tool does not use cookies or tracking.

Retention and deletion

Local records are kept as long as the owner needs them and can be deleted at any time by deleting the files. Data on YouTube is governed by YouTube and Google.

Revoking access

Access can be revoked at any time from the Google Account security settings page: https://myaccount.google.com/permissions

Contact

Please open an issue at https://github.com/OyogeTaiyaki/taidan-publish/issues

プライバシーポリシー — taidan publish

最終更新: 2026-10-01

taidan publish (以下「本ツール」) は、YouTube チャンネル「スタジオともしび」の持ち主 (以下「私たち」) だけが使う、手元のパソコンの道具です。持ち主が自分のチャンネルに上げた動画に、題・説明・サムネイル・字幕・改変または合成したコンテンツの開示・予約公開の時刻を設定するために使います。一般には公開しておらず、ほかの利用者はいません。

YouTube API サービス

本ツールは YouTube API サービスを使っています。本ツールを使うことで、YouTube 利用規約に同意したことになります。Google のプライバシーの取り扱いは、Google プライバシー ポリシーに書かれています。

読む情報

持ち主の許可 (OAuth のスコープ youtube.force-ssl) のもとで、持ち主自身の動画の情報 (題・説明・タグ・公開の状態・予約公開の時刻・合成の開示)・サムネイル・字幕を読み書きし、許可したチャンネルを確かめるためにチャンネル名を読みます。ほかの人のデータ・コメント・アナリティクス・個人情報には触れません。

保存する情報

認可の鍵 (OAuth のトークン) は持ち主のパソコンの中だけに置きます (共有や公開の場所には置きません)。送った内容の記録 (動画 ID・題・設定) を、持ち主が見返すために手元に残します。Google の YouTube API 以外のサーバーには何も送らず、第三者に売ったり渡したりしません。Cookie や追跡は使いません。

保存の期間と削除

手元の記録は持ち主が必要な間だけ残し、ファイルを消せばいつでも削除できます。YouTube 上のデータは YouTube と Google の規約に従います。

許可の取り消し

Google アカウントのセキュリティの設定 (https://myaccount.google.com/permissions) から、いつでも取り消せます。
